# Parth Khiriya - Personal Portfolio 🚀

Welcome to the repository of my personal portfolio website! This project serves as an interactive resume and showcase of the various projects, skills, and experiences I've accumulated as a developer and engineer. 

## 🌟 Overview
This portfolio is designed to be highly interactive, sleek, and modern. It utilizes advanced scroll-based animations, dynamic layouts, and custom visual elements to create an engaging experience for visitors.

## 🛠️ Tech Stack
- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Styling:** Vanilla CSS (with modern features like custom properties, grid, and flexbox)
- **Animations:** GSAP (GreenSock Animation Platform) & ScrollTrigger

## ✨ Features & Sections

- **Dynamic Hero Section:** Welcoming intro with smooth staggered animations.
- **About Me:** A brief look into my background, education (B.Tech EE at IIT Jodhpur), and development philosophy.
- **Technical Arsenal (Bento Grid):** A dynamic, Pinterest-style masonry grid that categorizes my skills across Machine Learning, Backend, Frontend, Programming, and more.
- **Experience:** A clean timeline detailing my professional journey, including my internship as a Web Designer & Developer.
- **Projects (Horizontal Scroll):** A custom GSAP-powered horizontal scrolling section that beautifully highlights my projects:
  - NeuroClaw (Autonomous AI coding assistant)
  - Resume AI (AI-powered mock interview platform)
  - AudioCNN
  - LaneNet
  - QuickChat
  - Tweet Sentiment Analyzer
  - GraphDB
  - ThinkBoard
- **Contact:** An interactive contact section featuring a custom HTML5 Canvas ripple effect on mouse movement, along with links to my GitHub, LinkedIn, and Resume.

## 🚀 Running Locally

To get a local copy up and running, follow these simple steps:

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation
1. Clone the repo
   ```sh
   git clone https://github.com/ParthKhiriya/react-portfolio.git
   ```
2. Navigate into the directory
   ```sh
   cd react-portfolio
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Start the Vite development server
   ```sh
   npm run dev
   ```
